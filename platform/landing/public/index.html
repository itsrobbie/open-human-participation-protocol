OHPP World

A window into the Open Human Participation Protocol — the layer that proves a human really participated.

The internet was built assuming a human is at the keyboard. As AI agents act on our behalf, OHPP lets any application request — and cryptographically verify — that a human was meaningfully involved in a decision. Everything below is running locally on your machine.

Start here

New to OHPP? Follow this two-minute path to see a full human-participation ceremony end to end.

  1. 1
    Open a demo app — sign in to the Bank with demo / demo and make a transfer. It completes instantly, no OHPP.
  2. 2
    Connect it to OHPP — from the Bank's Settings, connect to OHPP, then manage the connection in the Portal.
  3. 3
    Act like a human — make another transfer. This time it waits for approval. Approve it from the Portal's Pending page (or run the CLI attester: make cli).
  4. 4
    Watch it flow — open Grafana and follow the ceremony as a single trace across every service.

Observability the single pane

Every service streams telemetry here. Grafana is the one dashboard for logs, traces and metrics.

Grafana ↗

The single pane of glass: logs (Loki), traces (Tempo) and metrics (Prometheus), correlated. Start with the "Follow a ceremony" dashboard.

localhost:3001

Prometheus ↗

Raw metrics store and query UI for every service (by job).

localhost:9090

GlitchTip ↗

Crash and error reporting (Sentry-compatible). Where app exceptions surface.

localhost:8000

Umami ↗

Product analytics — events, funnels, retention. Opt-in: make dev-analytics. Sign in with admin / umami.

localhost:8001

Dev tools

Run from your terminal at the repo root. See make help for everything.

CLI attester

A terminal stand-in for the mobile app: registers a device, receives requests, signs attestations.

make cli

Verify observability

Drives real world-actions and confirms every backend's data lands in the dashboards.

make verify-observability

Verify analytics

Emits an event and confirms it is ingested by Umami.

make verify-analytics

Verify cert pinning

Confirms the app accepts the real Resolver cert and rejects a wrong one (fail-closed).

make flutter-verify-pinning

Everything here runs locally over HTTPS with a local certificate authority, and needs no vendor accounts. This page is the front door — make help lists every command.
